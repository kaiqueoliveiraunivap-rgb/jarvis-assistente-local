J.A.R.V.I.S. 1.0.0 PARA WINDOWS
================================

INSTALACAO RECOMENDADA

1. Extraia TODO o conteudo deste ZIP para uma pasta.
2. Execute install.bat.
3. Siga as perguntas do instalador.
4. Abra J.A.R.V.I.S. pelo atalho ou por start_jarvis.bat.
5. Conclua o assistente da primeira execucao.
6. Ative o microfone e diga "Jarvis".

IMPORTANTE

- Nao e necessario instalar Python.
- Ollama e opcional para comandos diretos, mas necessario para conversas com IA local.
- Instale Ollama em https://ollama.com/download/windows e use: ollama pull qwen3:4b
- O modelo faster-whisper nao esta no ZIP. O instalador oferece seu download controlado.
- O TTS padrao usa as vozes do Windows. Piper e opcional e nao esta incluido.
- Configuracoes, banco, memorias, logs e cache ficam em %LOCALAPPDATA%\JARVIS.
- O modo debug esta em start_debug.bat.
- Para remover o programa, execute uninstall.bat.

PRIVACIDADE

Captura de tela so ocorre quando permitida. Acoes destrutivas exigem confirmacao.
O pacote nao contem tokens, senhas, logs, memorias nem configuracoes pessoais.

VERSAO PORTABLE

Na edicao Portable, execute JARVIS.exe diretamente. Dados ficam na propria pasta.
Mantenha a pasta extraida em um local com permissao de escrita.

Documentacao tecnica completa: README.md
